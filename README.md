# krmy1979.github.io

האתר הראשי של החשבון. יש בו:
- `index.html` – דף פתיחה קטן עם קישור ל־OrKeepers בלבד (האפליקציה עצמה נמצאת ב־/shapeland).
- `.well-known/assetlinks.json` – (יתווסף בהמשך) הקובץ שמאמת מול גוגל פליי שהאפליקציה OrKeepers והאתר שייכים לאותו בעלים.
- `.nojekyll` – כדי שגיטהאב תפרסם גם תיקיות שמתחילות בנקודה (כמו `.well-known`).
